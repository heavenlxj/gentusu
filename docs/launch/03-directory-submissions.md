## 提交注意事项

- 每个站点字段长度不同，逐站裁剪；不要超出字符限制被截断
- 分类优先选 Video Editing / Generative Video / Content Creation
- 提交时勾选 "Freemium" 或 "Free trial"（有免费额度）
- 商业使用描述统一 "Pro and Studio"，不得写 "Creator"
- 站点允许时，描述末尾追加 "Not affiliated with Higgsfield."
- 红线检查：不得出现任何模型名 / 供应商名 / 基础设施名 / API / 阈值 / 管线描述；
  技术表述只用 "our in-house generation pipeline" / "state-of-the-art generative video models"

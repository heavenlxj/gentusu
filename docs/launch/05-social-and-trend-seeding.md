# 社交与趋势种草（Social & Trend Seeding）

> **相对参考项目新增的第 6 个文件。** 参考项目（lipread）的渠道只有 PH / HN / 目录站 / 通用素材
> 这 5 个文件；Genjutsu AI 的传播主要靠短视频平台（TikTok / Instagram Reels / YouTube Shorts），
> 因此额外增加本文件，专门放"可直接复制"的短视频钩子文案、话题标签、模式差异化选题与 UGC 引导。
>
> 核心公式：**before / after 对比** + 一句话钩子 + 模式名。竖版 9:16，前 1.5 秒必须出现变化。
> 所有英文文案末尾带 `Not affiliated with Higgsfield.`（简介区或首评/置顶评论）。

```

while the face, outfit and style stay locked. #motiontransfer #aivideo #beforeandafter

Not affiliated with Higgsfield.

```
Recast the performer in a clip you already shot — from a single photo. Background,

Not affiliated with Higgsfield.

## 发布注意事项

- 前 1.5 秒必须出现画面变化，否则完播率会崩
- 一条视频只讲一个模式；合辑留给周末
- Face Swap 内容务必带 consent 与 safety 的置顶评论，避免被平台判定违规
- 所有英文文案带 "Not affiliated with Higgsfield."；中文平台文案不动产品事实
- 不新增未经验证的数字；免费额度表述统一为"30 credits / 一条 6s 480p 视频"
- 红线检查：不得出现任何模型名 / 供应商名 / 基础设施名 / API / 阈值 / 管线描述；
  技术表述只用 "our in-house generation pipeline"
